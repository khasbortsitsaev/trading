# Longer-term research context

The immediate goal is capital growth from a repeatable edge after costs. Relatively passive income, continuous hosting and lower-frequency equities are possible later directions, not current withdrawal targets or deployment authority.

BTC dependence is an untested hypothesis: common movement is not predictive alpha. If examined later, compare lagged BTC features with an own-price baseline using chronological data and after-cost P&L. No broad correlation study is needed to finish S1.

Background sources, not project replications: [IMF crypto-cycle paper](https://www.imf.org/en/publications/wp/issues/2023/08/04/the-crypto-cycle-and-us-monetary-policy-534834) and [Liu, Tsyvinski and Wu](https://www.nber.org/papers/w25882). Detailed historical discussion remains in Git history.
